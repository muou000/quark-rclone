# Release Gates And Compatibility Matrix

首版只承诺 Windows 10/11 x64；其他 Windows 版本和架构显示为未验证。发布前必须使用专用夸克测试账号完成 Cookie 验证、根目录列举、下载、上传、建目录、移动、重命名、删除、会话刷新和认证失效恢复；Copy 不纳入测试，因为它是明确不支持的能力。

阻断测试覆盖 WinFsp 缺失与架构错误、盘符冲突、网络断开恢复、睡眠唤醒、注销/关机卸载、dirty cache 回写和升级回滚。配置与安全门槛覆盖旧版本迁移备份/回滚、更高版本拒绝、DPAPI 解密失败、日志脱敏、rclone SHA-256 校验和 staging 回滚；任一敏感信息泄露或数据丢失风险都阻断发布。

任何核心流程失败都阻断发布：Cookie 验证、适配层健康、盘符可见性、读写回写、认证失效恢复、WinFsp 预检和卸载清理。已记录且不影响数据安全或核心挂载流程的 UI 小问题可以作为非阻断项发布。

这套门槛把“已验证的首版组合”限定为 Windows 10/11 x64，并要求真实夸克服务和真实 WinFsp 生命周期参与发布验证；本地模拟测试可以辅助定位，但不能替代集成门槛。
