# Writes Cache And Failure Semantics

首版盘符使用 rclone `vfs-cache-mode writes`。文件关闭后异步回写夸克；失败时保留 dirty cache、标记上传失败并进行有限重试，不能把本地文件伪装成远端成功。断网时新的目录、属性和读取请求明确失败并进入恢复状态，已有 dirty cache 继续可见、可读、可写，网络恢复后再回写。目录缓存沿用 rclone 默认较长 TTL，属性缓存保持约 1 秒级别。

本地目录视图在内部 API 成功后立即更新，API 失败不更新；不支持的 Copy 返回明确错误，覆盖上传返回冲突，能力探测和状态页列出这些限制。dirty cache 在用户清理前不自动删除。

这套语义把“本地写入已接受”和“远端已确认”分开，适配 Windows 应用的 seek 和普通写入，同时避免在断网或 Quark 最终一致性期间伪造数据安全状态。它不是离线同步，未缓存的远端读取不会在断网时凭空可用。
