# User Logon Recovery State Machine

首版在当前 Windows 用户登录时注册并启动托盘程序，以非提升权限运行，不使用 SYSTEM 服务。启动后先做 WinFsp 与盘符预检，再以 Quark `/config` 和适配层健康检查作为真实就绪条件；健康后启动 rclone，盘符可访问后才进入 `Mounted`。网络未就绪采用 5 秒、15 秒、30 秒、60 秒、5 分钟的指数退避并持续重试，直到成功、`NeedsReauth` 或用户禁用自动恢复。

盘符占用进入 `DriveConflict`，WinFsp 缺失或架构不匹配进入 `WinFspRequired`；这两个状态暂停自动重试，由托盘提供重新检查或更换盘符操作。注销或关机前停止接受新的挂载请求，按卸载盘符、停止 rclone、停止 Quark adapter 的顺序清理；从睡眠恢复后重新执行同一套预检、健康检查和重试状态机。

这样区分暂时网络故障、需要用户修复的本地环境故障和需要重新认证的凭据故障，避免后台无限重试已知无法成功的挂载，同时保留用户登录后的自动恢复体验。
