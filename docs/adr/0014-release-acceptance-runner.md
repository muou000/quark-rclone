# Release Acceptance Runner

ADR 0007 规定了发布门槛与兼容矩阵的语义。本文记录验收矩阵的执行形态（issue #26）：`quark-adapter accept` 作为唯一入口，按三层执行并以退出码阻断发布。

## 三层矩阵

| 层 | 内容 | 执行方式 | 阻断性 |
|---|---|---|---|
| **测试套件** | 配置迁移/版本拒绝/DPAPI（profile 包）、日志脱敏（redact）、rclone SHA-256（preflight）、staging 回滚（upgrade）、生命周期行为（supervisor/dav/power/singleinstance）、托盘流程（trayui 等） | `go test -race -count=1` 外部进程，按关注点分六个门槛 | 阻断 |
| **运行时门** | WinFsp 预检、rclone 运行包版本+清单、适配层 healthz/capabilities、升级 staging 换位+回滚往返、单实例守卫、自启动注册（scratch 键） | 进程内直接执行，无需凭据 | 阻断 |
| **专号 live** | Cookie 验证、根目录列举、建目录、上传、下载校验、移动、重命名、删除并验证消失、会话刷新、认证失效与恢复、Copy 反向断言 | 经 `Provider` 接口对真实夸克服务；凭据用一次性会话，不触操作者 profile | 阻断 |

live 层的写入全部发生在验收目录 `quark-release-gate-<时间戳>` 内，矩阵结束无论成败尽力删除；后置失败会毒化后续 live 门槛（快速失败并注明前置原因），不允许级联出无意义的级联错误。

## 范围与退出码

- 已验证范围：Windows 10/11 x64（构建号 22000 分界由版本号而非 ProductName 判定）。其它版本/架构在报告中标记**未验证**——是披露，不是阻断（ADR 0007 的"显示为未验证"）。
- 退出码：**0** 全部通过（含 live）；**1** 存在未通过的阻断项；**2** live 层未执行（发布验证未完成，不是失败）。`-skip-tests` 仅用于开发迭代，发布流程禁止。
- 睡眠唤醒真机、注销/关机真机、真实 WinFsp 安装流程无法在进程内自动化：报告列出人工验证清单，发布负责人签收。

## 后果

- 测试套件门需要 Go 工具链：验收在构建机执行；已安装二进制上 skip-tests 的运行只能覆盖运行时层，报告如实显示未执行的层。
- live 门槛对专用账号有写操作（全部在验收目录内并被清理）；专用账号与个人账号隔离是 ADR 0007 的前提，不是本 runner 能强制的事项。
